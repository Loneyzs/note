# FDSim 已验证操作

## 验证基线

- 测试日期：2026-07-13
- 平台版本：FDSim 4.3.7
- 测试工程：`test` 最小工程
- 证据状态：界面入口与配置能力已检查；没有真实 OPC UA 服务和 10 张样本图片，因此相关闭环仍待实测。

## 1. UR5 固定点位运动

证据：`界面已见` + `文档确认`，端到端运动待验证。

1. 进入“布局”，展开“模型资源管理器”。
2. 依次进入“公共 → UR → Robot”，把 `UR5` 加入场景。
3. 在行为树确认存在机器人控制器、机器人执行器、输入/输出信号集合、机器人容器和工具容器。
4. 进入“编程”，在 `Main` 中添加“点对点运动”，记录 `P1`。
5. 调整末端目标位姿，再添加点对点运动，记录 `P2`。
6. 使用机器人控制器完成末端逆运动学；不要从 OPC UA 实时计算并写入六个关节角。
7. 按以下结构编排固定动作：

```text
等待 Start 上升沿
PTP P1
PTP P2
设置 Done = true
等待 Start 下降沿
设置 Done = false
循环
```

可见程序指令包括：点对点运动、线性运动、路径运动、关节运动、等待输入、等待、设置输出、条件、循环、变量赋值、程序调用和信号连接。

## 2. OPC UA 变量映射

证据：`界面已见`，真实服务器连接待验证。

1. 进入“通信 → OPC UA”，点击“添加服务器”。
2. 填写名称、服务器地址和认证方式；认证方式可见无认证、密码和证书。
3. 点击“测试连接”，成功后应用。
4. 打开“可配置节点”，确认需要暴露的输入、输出或变量。
5. 点击“配对变量”，把外部节点映射到 `Start` 和 `Done`。
6. `Start` 用于外部写入；`Done` 配置反向写入，由 FDSim 回写。
7. 在“显示变量”中检查数据类型、当前值和通信状态。
8. 用真实服务器验证 `Start: false → true → 动作 → Done: true` 完整握手。

## 3. 贴图样本资产

证据：`界面已见` + `文档确认`，批量 10 样本待验证。

1. 在资源管理中打开“贴图库 → 私有”，新建 `vision_samples` 文件夹。
2. 上传图片并命名为 `sample_01`、`sample_02` 等稳定编号。
3. 在组件编辑中添加“基础网格 → 长方体”。
4. 选择长方体网格，在材质的颜色贴图中选择私有贴图或本地上传。
5. 若只需顶面显示图片，添加薄平面作为标签面，并设为双面材质。
6. 将组件命名为 `SampleBox_01` 等，保存到私有组件库。
7. 先完成 2 个样本的生成与输送验证，再扩展到 10 个。

资源管理中已见：组件库、零部件库、贴图库、环境贴图库和场景背景图库。

## 4. 生成与传送流程

证据：相关行为入口 `界面已见` + `文档确认`，完整物流循环待验证。

1. 添加传送带；若没有合适模型，使用“单向”物流行为和坐标框定义路径。
2. 给生成器组件添加“创造者”行为。
3. 把创造者的 `Output` 连接到传送带或容器的 `Input`。
4. 在拍照位置使用“容器”暂存样本，在末端使用“销毁”回收。
5. 通过逻辑控制器或脚本按 `SampleIndex` 选择样本模板并触发创造者。
6. 样本到位后回写 `Arrived=true`；视觉程序完成后写入 `VisionDone=true`，再放行。

物流行为菜单已见：创造者、单向、容器、销毁、排程规则。

## 5. 可复现随机顺序

证据：推荐控制方案，场景内随机选择细节 `待验证`。

1. 外部程序使用固定随机种子生成样本编号序列。
2. 通过 OPC UA 写入整数 `SampleIndex`，再脉冲触发 `Create`。
3. FDSim 根据编号选择对应模板并生成物块。
4. 保存随机种子、生成顺序、识别结果和时间戳。
5. 用相同种子重跑，确认顺序一致。

## 已知限制

- 创建点位时可能出现姿态预览或幽灵模型，不应把预览误认为第二个机器人。
- 当前未确认创造者是否直接支持“从多个模板随机选择”；采用 `SampleIndex` 显式控制。
- 当前未完成真实 OPC UA 服务器连接、机器人运行和 10 样本连续循环，不能宣称端到端通过。
