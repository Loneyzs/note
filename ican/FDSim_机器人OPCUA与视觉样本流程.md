# FDSim：机器人 OPC UA 控制与视觉样本生成

适用界面版本：FDSim 4.3.7。

## 一、用 OPC UA 触发机器人固定运动（以UR5为例）

### 1. 添加机器人

1. 进入项目，选择“布局”。
2. 展开左侧“模型资源管理器”。
3. 依次选择“公共 → UR → 机器人 → UR5”。
4. 将 UR5 拖入场景。

UR5 已自带以下行为：

- UR 机器人控制器；
- 机器人执行器；
- 输入、输出信号集合；
- 工具和底座拼合接口。

### 2. 示教固定点位

1. 选择 UR5，进入“编程”。
2. 在 `Main` 程序中点击“点对点运动”，记录当前末端位姿为 `P1`。
3. 点击“平移/旋转”，移动末端到目标位置；机器人控制器会自动做末端逆解。
4. 再次点击“点对点运动”，记录为 `P2`。
5. 按需要继续添加 `P3...Pn`。
6. 在程序开头添加“等待输入”，选择一个输入信号，例如 `Start`，触发方式选“上升沿”。
7. 在动作末尾添加“设置输出”，置位 `Done`；如需循环，再加入循环语句并等待 `Start` 复位。

推荐程序结构：

```text
等待 Start 上升沿
PTP P1
PTP P2
设置 Done = 1
等待 Start 下降沿
设置 Done = 0
循环
```

说明：固定动作只需通过 OPC UA 触发程序，不要通过 OPC UA 实时写入六个关节角度。点位、速度和运动解算应留给 FDSim 的机器人控制器。

### 3. 配置 OPC UA

1. 进入“通信”。
2. 在“服务器列表”选择 `OPC UA`，点击“添加服务器”。
3. 填写名称和服务器地址，例如 `opc.tcp://192.168.1.10:4840`。
4. 验证方式选择“无”“密码验证”或“证书验证”。
5. 点击“测试连接”，成功后点击“应用”。
6. 点击“可配节点”，筛选“信号 → 输入类型”，确认 `Start`；筛选“输出类型”，确认 `Done`。
7. 点击“配对变量”，将 OPC UA 节点分别绑定到 `Start` 和 `Done`。
8. `Start` 是外部写入 FDSim 的命令；`Done` 勾选“反向写入”，由 FDSim 回写 OPC UA。
9. 点击“显示变量”，检查值、数据类型和通信状态。
10. 启动仿真，在 OPC UA 客户端把 `Start` 从 `false` 写为 `true`，确认 UR5 执行固定动作并回写 `Done=true`。

## 二、十张视觉样本随机送上传送带

### 1. 建立贴图资产库

1. 返回“在线开发 → 资源管理 → 贴图库”。
2. 在“私有”中新建文件夹 `vision_samples`。
3. 上传十张图片，命名为 `sample_01` 至 `sample_10`。

### 2. 建立十个样本物块

对每张图片执行一次：

1. 进入项目“建模”，点击“新建组件 → 默认组件”。
2. 点击“基础网格 → 长方体”，调整长、宽、高。
3. 在结构树中选择长方体网格，打开材质设置。
4. 在“颜色贴图”中选择“贴图库上传”，选择对应的 `sample_XX`。
5. 图片只显示在指定表面时，使用一个薄平面作为标签，并将平面贴到长方体顶面；材质设为双面。
6. 将组件命名为 `sample_box_01` 至 `sample_box_10`。
7. 点击“保存”，存入私有组件库文件夹 `vision_sample_boxes`。

### 3. 搭建生成和输送链

1. 从公共组件库拖入传送带；没有合适模型时，用“单向”物流行为和坐标框建立输送路径。
2. 新建一个生成器组件，添加“创造者”行为。
3. 将创造者的 `Output` 连接到传送带或容器的 `Input`。
4. 传送带末端接“容器”或“销毁”行为；需要拍照的位置用容器暂存样本。
5. 将十个 `sample_box_XX` 设为可生成模板。

### 4. 随机顺序

推荐使用“可复现随机”流程：

1. 外部验证程序用固定随机种子生成 `1~10` 的随机排列。
2. 通过 OPC UA 写入整数变量 `SampleIndex`，并脉冲触发 `Create`。
3. FDSim 中用逻辑控制器或脚本行为，根据 `SampleIndex` 选择对应样本模板，再触发创造者。
4. 样本到达拍照位置后，FDSim 回写 `Arrived=true` 和当前 `SampleIndex`。
5. 视觉程序完成推理后写入 `VisionDone=true`，容器放行样本。
6. 保存随机种子、生成顺序、识别结果和时间戳，便于复现实验。

如果不需要复现，可在脚本行为中随机选择 `1~10`。不要仅依赖未验证的“随机”界面选项；当前官方说明确认创造者支持按信号或时间生成，排程规则支持由信号或脚本控制。

## 三、验收清单

- OPC UA 的 `Start` 能触发 UR5 的 `P1 → P2` 固定动作。
- FDSim 能回写 `Done`。
- 十张图片分别显示在十个样本物块上。
- 每轮只生成一个样本，顺序与随机序列一致。
- 样本沿传送带到达拍照位置并等待视觉完成信号。
- 同一随机种子可复现相同顺序。
