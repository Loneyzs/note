### PLCnext	

* 比赛用vplc，添加用户库，vplc500。
  * 有vplc授权之前用仿真使用1152 2023平台。选中复制到workspace下 / 替换原有从而用仿真器
* 变量：IEC 61131-3 -> 默认值 -> 上方 “变量” 三角
* 程序：右侧组件 -> 编程 -> 局部 -> 程序 -> 右键添加程序
* 调试下载：
  * 创建任务：左侧工程树窗口 -> PLCnext -> 添加任务
  * 添加程序：右侧程序拖进来
  * 下载调试：左侧工程树窗口 -> 项目名 -> cockpit -> 选择设备TCP/IP 或 仿真程序 -> 左侧工程树窗口右键写入并启动项目
  * 用户名 `admin` ，密码 `plcnext` 
  * 下载后进入代码页面，箭头进入调试，手动改变状态调试
* hmi页面：
  * 变量监视：最下方有变量监视窗口、逻辑分析器等调试工具。右键代码变量，添加到xx，进行监视
  * HMI页面：
    * 左侧工程树窗口 -> HMI网络服务器 -> 应用程序 -> 右键添加 -> 设置为起始页
    * 回到变量表 -> 右键变量 -> 添加HMI标签
    * 回到HMI页面 -> 右侧组件 -> HMI -> 添加对象 -> 行为-绑定变量 / 动态-填充 / .....
    * 写入并启动项目 -> 双击项目 -> 上方标签栏启动默认浏览器显示HMI页面
  * HMI -> 安全 -> 用户... 可去掉登陆
  * 输入输出：添加变量 -> 文本 / 文本输入 -> 动态-Text-文本



### 数字孪生

b站，8h视频，学习

**通信**：OPC UA通信

**开发步骤**：

* 场景开发：直接使用平台库 / 机械3D导入
* 场景参数设置：动作、工艺
  * 加入PLC UPC UA通信交互变量
* PLC程序，控制逻辑
  * 需要PLC进行控制的上述（同一个）变量，变量表勾选上OPC
* PLC和FDsim的通信联调（以下是基于本机仿真器时，实际使用vplc时本机地址应该改为vplc地址）
  * 使用UA expert工具测试PLC侧是否正确发出
    * 首先PLCnext下载运行到仿真器
    * severs右键添加服务器 -> local -> 选择一个 -> 右键connect -> 信任证书 -> 左下角找到PLCnext查看变量
  * 使用datacollecter工具
    * 初始配置：设置 -> `服务端` & `数据源 OPC UA` 应用
    * 配置fdsim：网址UID `scene=xxx` 填入主界面 -> 选择`webScoket服务端` ， `localhost8068`
    * 配置plc：上方OPC UA -> 管理 -> 添加 `opc.tcp://localhost:4840` （使用vplc则改为实际地址）及登陆信息 -> 连接
    * 关联变量配对：同时选中左右同一个变量，PLC输出变量 `读写配对`；PLC输入变量 `写入配对`
    * fdsim配置服务器：服务器地址 复制到 fdsim 通信 -> 自定义服务器 -> datacollecter开启连接
